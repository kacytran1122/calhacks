# Claude in S'mile

Claude is the system's language, extraction, and explanation layer.

It can:

- read unstructured event and fare evidence into validated schemas;
- interpret a traveler's written constraints;
- choose approved planning tools for the private `@smile` concierge;
- explain deterministic finance decisions from a closed evidence trace;
- answer an auditor's question with validated evidence and policy citations.

Claude cannot approve a fare, calculate the authoritative reimbursement amount, charge a card, reimburse a traveler, post to the ledger, or override policy. Those actions stay in deterministic code with role checks and human approval where required.
